# Документация — схемы подключения

Материалы этой папки описывают аппаратное подключение контроллера ESP32 (DOIT DEVKIT V1) по актуальной распиновке из [`include/config.h`](../include/config.h).

## Файлы

- **[pinout-v2.html](pinout-v2.html)** — распиновка платы «как есть»: физическое расположение пинов 1–38, 8-канальный блок реле, отдельное реле насоса скважины, датчики (BME280, GY-30/BH1750, DHT22, YL-83, AJ-SR04M) и 5 подписанных кнопок. Линии проложены без пересечений.
- **[principal-schematic.html](principal-schematic.html)** — принципиальная электрическая схема в условных обозначениях IEC 60617: питание с защитой (предохранители, диоды, конденсаторы), типовой опто-релейный канал, реверсивные приводы форточек, делитель напряжения на ECHO.

Оба файла — самодостаточные HTML-страницы (SVG внутри), открываются в любом браузере без интернета.

## Ключевые моменты по распиновке

| Назначение | GPIO | Примечание |
|---|---|---|
| Полив 1 / 2 / 3 | 25 / 26 / 27 | реле, блок 8ch |
| Форточка ВЕРХ откр. / закр. | 32 / 4 | реле, блок 8ch |
| Форточка НИЗ откр. / закр. | 33 / 15 | реле, блок 8ch; **GPIO15 требует pull-down 10кΩ на GND** |
| Увлажнитель | 14 | реле, блок 8ch |
| Насос скважины | 5 | отдельное реле, вне блока 8ch |
| BME280 / GY-30 (I²C) | SDA 21, SCL 22 | общая шина |
| DHT22 | 13 | наружная т/влажность |
| YL-83 (дождь) | 39 | вход-only, активен LOW |
| AJ-SR04M (уровень воды) | TRIG 0, ECHO 34 | **ECHO — через делитель 1кΩ/2кΩ (5V→3.3V)** |
| Кнопки (Полив-1/2/3, Открыть/Закрыть форточки) | 18, 17, 16, 23, 19 | INPUT_PULLUP, замыкание на GND, без резисторов |
| LED heartbeat | 2 | встроенный, 1 Гц |
