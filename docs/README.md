# Документация — схемы подключения

Материалы этой папки описывают аппаратное подключение контроллера ESP32 (DOIT DEVKIT V1) по актуальной распиновке из [`include/config.h`](../include/config.h).

## Файлы

- **[cheme.png](cheme.png)** — схема подключения: плата, 8-канальный блок реле, отдельное реле насоса, датчики и кнопки.
- **[GPIO_ESP32.ru.xlsx](GPIO_ESP32.ru.xlsx)** / **[GPIO_ESP32.xlsx](GPIO_ESP32.xlsx)** — табличная распиновка по выводам платы, русская и английская. Печать на A4, альбомная ориентация. Собираются из одного источника скриптом `tools/build_gpio_docs.py`.

Ранее здесь лежали `pinout-v2.html` и `principal-schematic.html`. Они были отрисованы по распиновке до версии 6.2 и удалены, чтобы не расходиться с кодом. При необходимости их можно достать из истории git.

## Ключевые моменты по распиновке

| Назначение | GPIO | Примечание |
|---|---|---|
| Полив 1 / 2 / 3 | 25 / 26 / 27 | реле, блок 8ch |
| Форточка ВЕРХ откр. / закр. | 32 / 4 | реле, блок 8ch |
| Форточка НИЗ откр. / закр. | 33 / 15 | реле, блок 8ch; **GPIO15 требует pull-down 10 кΩ на GND** |
| Увлажнитель | 14 | реле, блок 8ch |
| Насос скважины | 5 | отдельное реле, вне блока 8ch |
| BME280 / GY-30 (I²C) | SDA 21, SCL 22 | общая шина |
| DHT22 | 13 | наружная т/влажность, **только мониторинг** |
| YL-83 (дождь) | 36 | **аналоговый вход** ADC1_CH0; пороги в `config.h` |
| AJ-SR04M (уровень воды) | TRIG 0, ECHO 34 | **ECHO — через делитель 1,5 кΩ/2,2 кΩ (5V→3.3V)** |
| Кнопки полива 1/2/3 | 18, 17, 16 | INPUT_PULLUP, замыкание на GND, без резисторов |
| Кнопки Открыть / Закрыть форточек | 23, 19 | INPUT_PULLUP, удержание |
| Кнопка увлажнителя | 35 | **вход-only: внешний pull-up 10 кΩ + 100 нФ** |
| Кнопка насоса | 39 | **вход-only: внешний pull-up 10 кΩ + 100 нФ** |
| LED heartbeat | 2 | встроенный, 1 Гц |
| GPIO12 | — | **не использовать**: strapping-пин напряжения флеш-памяти |
